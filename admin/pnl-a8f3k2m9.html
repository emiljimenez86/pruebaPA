Para usar el panel con publicación directa en la web, configura Firebase:

  1. Copia js/firebase-config.example.js como js/firebase-config.js.
  2. Crea un proyecto en Firebase, activa Firestore y Authentication (Email/Password).
  3. Pega en firebase-config.js la configuración de tu app web.
  4. Crea un usuario en Authentication → Users y usa ese correo y contraseña aquí.

Publicar nueva propiedad

Los clientes envían el formulario por WhatsApp; tú subes aquí la información, imágenes y videos.

Separa las URLs con coma o una por línea. La primera es la imagen principal. Puedes pegar el enlace normal de Google Drive (Compartir → copiar enlace); la web lo convertirá para que se vea. Si aun así no carga, usa el formato directo: https://drive.google.com/uc?export=view&id=ID (el ID está en el enlace: drive.google.com/file/d/ID/view). Para máxima compatibilidad en todos los celulares, puedes usar enlaces directos de Imgur u otro host de imágenes.

Propiedades publicadas

Aquí puedes editar o eliminar las propiedades. Con Firebase, los cambios se ven en la web al instante.

Para instalar el panel de administración en tu iPhone:

  1. Toca el botón Compartir ⬆️ en Safari.
  2. Elige Añadir a pantalla de inicio.
  3. Confirma tocando Añadir.
